   - 结论

1. 跑 2 道 SPSS。

1. 跑 3-4 道混合 SPSS。
2. 做一组限时选择题。
3. 更新“最后不会清单”。

## 四、方法选择保命表

| 题干关键词 | 方法 | SPSS 入口 |
|---|---|---|
| 一个计量变量描述 | 描述统计 / Explore | `Analyze > Descriptive Statistics > Explore` |
| 频数、率、构成比 | Frequencies / Crosstabs | `Analyze > Descriptive Statistics` |
| 一个样本均数 vs 已知值 | 单样本 t 检验 | `Analyze > Compare Means > One-Sample T Test` |
| 同一批对象前后 | 配对 t 检验 | `Analyze > Compare Means > Paired-Samples T Test` |
| 两独立组均数 | 独立样本 t 检验 | `Analyze > Compare Means > Independent-Samples T Test` |
| 三组及以上均数 | 单因素方差分析 | `Analyze > Compare Means > One-Way ANOVA` |
| 两个分类变量 | χ²检验 | `Analyze > Descriptive Statistics > Crosstabs` |
| 配对等级/偏态资料 | Wilcoxon | `Analyze > Nonparametric Tests > Legacy Dialogs` |
| 两独立组等级/偏态资料 | Mann-Whitney U | `Analyze > Nonparametric Tests > Legacy Dialogs` |
| 多组等级/偏态资料 | Kruskal-Wallis H | `Analyze > Nonparametric Tests > Legacy Dialogs` |
| 两个计量变量关系 | Pearson 相关 | `Analyze > Correlate > Bivariate` |
| 计量因变量 + 自变量 | 线性回归 | `Analyze > Regression > Linear` |
| 二分类因变量 + 自变量 | Logistic 回归 | `Analyze > Regression > Binary Logistic` |

## 五、输出表保命表

| 方法 | 输出表 | 看什么 |
|---|---|---|
| 单样本 t | One-Sample Test | `Sig.(2-tailed)` |
| 配对 t | Paired Samples Test | `Sig.(2-tailed)` |
| 独立样本 t | Independent Samples Test | 先看 Levene，再看对应行 `Sig.(2-tailed)` |
| 方差分析 | ANOVA | `Sig.` |
| χ²检验 | Chi-Square Tests | `Pearson Chi-Square` 的 `Asymp. Sig.` |
| 非参数 | Test Statistics | `Asymp. Sig.` |
| Pearson 相关 | Correlations | `Pearson Correlation` 和 `Sig.` |
| 线性回归 | Model Summary / ANOVA / Coefficients | `R Square`、整体模型 P、各变量 `B` 和 `Sig.` |
| Logistic 回归 | Variables in the Equation | `B`、`Sig.`、`Exp(B)` |
