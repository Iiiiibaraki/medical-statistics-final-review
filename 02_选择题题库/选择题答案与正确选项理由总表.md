# 选择题答案与正确选项理由总表

说明：本文件按原题库 11 个章节整理，共 146 题。每题给出正确选项和考场判断理由。少数原题选项疑似录入有误，已在理由中注明。

## 01. 绪论

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | B | 统计总体首先要求同质，即研究对象在主要影响因素上相同或相近。 |
| 2 | A | 同质不是完全一样，而是对研究指标有影响的因素相同或相近。 |
| 3 | D | 抽样研究的目的不是研究样本本身，而是由样本统计量推断总体参数。 |
| 4 | C | 抽样误差指样本统计量与总体参数之间由随机抽样造成的差异。 |
| 5 | C | 研究对象限定为“该地健康成年男性”的血红蛋白值，总体应对应所有这类指标值。 |
| 6 | C | 新疗法研究要推断的是所有接受该新疗法糖尿病患者的相关指标。 |
| 7 | C | 概率描述随机事件发生可能性的大小，不是“某样本事件发生的强度”。 |
| 8 | C | 系统误差可通过设计和控制尽量避免；测量误差和抽样误差通常难以完全避免。 |
| 9 | D | 统计分析主要包括统计描述和统计推断。 |
| 10 | C | 统计工作的基本步骤是研究设计、搜集资料、整理资料、分析资料。 |

## 02. 计量资料的统计描述

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | A | 中位数是集中位置指标，用于表示平均水平或集中趋势。 |
| 2 | C | 滴度资料常呈等比级数，平均水平宜用几何均数。 |
| 3 | B | 一端不确定或开口资料易受极端值影响，宜用中位数描述平均水平。 |
| 4 | B | 每个数都减同一常数，均数随之改变，离散程度标准差不变。 |
| 5 | B | 变异系数是标准差与均数的比值，反映相对离散程度。 |
| 6 | D | 偏态资料的离散程度宜用四分位数间距。 |
| 7 | C | 均数和标准差适合全面描述正态或近似正态资料。 |
| 8 | A | 身高和体重单位不同、均数不同，比较变异度应看变异系数。 |
| 9 | C | 偏态分布的集中趋势宜用中位数，抗极端值能力更强。 |
| 10 | E | 各值同乘非零常数后，均数、标准差、中位数和四分位数间距都会变，变异系数不变。 |
| 11 | A | 对称分布中均数与中位数相等；偏态分布二者通常不等。 |
| 12 | B | 变异系数 CV=标准差/均数 x 100%，即 6/162 x 100%。 |
| 13 | E | 变异系数大小取决于标准差和均数，不能固定判断大于或小于某值。 |
| 14 | E | 排序为 -3、-1、0、4、5、8，中位数为 (0+4)/2=2。 |
| 15 | D | 标准差可以小于、等于或大于均数，“不会小于算术均数”错误。 |
| 16 | B | 血清滴度按倍比变化，平均滴度宜用几何均数。 |
| 17 | C | 5 个数排序后居中的是 50。 |
| 18 | D | 潜伏期有 30 这个极端值，宜用中位数；8 个数中位数为 (3+4)/2=3.5 天。 |
| 19 | D | 身高和体重单位不同，不能直接比较标准差，应比较变异系数。 |
| 20 | B | 正态分布以均数为中心对称，均数到正无穷面积为 50%。 |
| 21 | A | 标准正态分布的均数为 0，标准差为 1。 |
| 22 | C | 标准差越大，数据越分散，正态曲线越扁平。 |
| 23 | D | 标准正态曲线下 -1.96 到 0 的面积为 47.5%。 |
| 24 | D | -2.58 到 0 约 49.5%，0 到 1.96 约 47.5%，合计约 97%。 |
| 25 | C | 标准正态曲线下 -1.96 到 1.96 约占 95%。 |
| 26 | E | 参考值范围覆盖比例要结合专业知识和研究目的确定。 |
| 27 | D | 参考值范围对象应排除患有影响该指标疾病的人，而不要求绝对“完全健康”。 |
| 28 | D | 参考值范围取单侧还是双侧由医学意义和专业目的决定。 |
| 29 | C | 判断个体指标是否异常，应与同类人群的 95% 或 99% 参考值范围比较。 |
| 30 | C | 算术均数利用了所有观察值的信息，比中位数信息利用更充分。 |

## 03. 参数估计与假设检验

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | D | 标准误越小，样本均数估计总体均数越稳定、可靠。 |
| 2 | C | P 越小，反对无效假设的证据越强，越有理由认为两总体均数不同。 |
| 3 | B | 已有明确方向性假设时可用单侧检验；本题对应 A 药优于 B 药。 |
| 4 | C | 配对设计控制个体差异，平均而言更容易检出现实存在的处理差别。 |
| 5 | E | 95% 可信区间为均数 ±1.96 x 标准误，标准误=4/sqrt(100)=4/10。 |
| 6 | E | 自由度相同时，|t| 越大，P 越小，不是越大。 |
| 7 | D | 两样本均数 t 检验的无效假设针对总体均数：两总体均数相等。 |
| 8 | E | 其他条件相同，α 越大，检验效能越高，第二类错误 β 越小。 |
| 9 | D | 正态性检验未拒绝 H0 若实际有错，属于第二类错误，其概率 β 未知。 |
| 10 | C | 假设检验的 H0 和 H1 都是针对总体参数或总体分布提出的。 |
| 11 | B | 第一类错误是 H0 实际为真，却被统计检验拒绝。 |
| 12 | D | 两样本均数 t 检验要求独立、正态、方差齐等，不要求两组均数相近。 |
| 13 | C | 配对 t 检验的核心条件是差值 d 近似服从正态分布。 |
| 14 | B | 两样本均数差异有统计学意义，推断的是两总体均数不同。 |
| 15 | E | 可信区间估计属于统计推断，样本均数和标准差是统计描述。 |
| 16 | C | 样本量越大，标准误越小，总体均数 95% 可信区间越窄。 |
| 17 | A | 可信度越高，临界值越大，可信区间越宽。 |

## 04. 方差分析

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | D | 完全随机设计方差分析的基本变异分解为 SS总=SS组间+SS组内。 |
| 2 | C | 完全随机设计中组内均方就是误差均方。 |
| 3 | D | 两组比较时方差分析与 t 检验等价，F=t²，所以 t 为 F 的平方根。 |
| 4 | A | F 值超过界值说明总体均数不等或不全相等，不能说全部两两不同。 |
| 5 | D | F 为两个均方之比，均方非负，所以 F 不会是负数；但可小于 1。 |
| 6 | C | 组间均方同时包含处理效应和随机误差，是二者综合结果。 |
| 7 | E | 方差齐性检验 P<0.01 时拒绝方差相等，认为各总体方差不等或不全相等。 |
| 8 | D | 题目选项疑似录入不理想；方差分析适用于分类分组与计量结局，本题中“难产分组比较产妇年龄”最接近。 |
| 9 | C | 方差齐性指各比较组所来自总体的方差相等。 |
| 10 | C | P<0.05 推断总体层面不同血型者血红蛋白均数不全相同。 |
| 11 | D | 多组均数若反复做两两 t 检验，会累积并增大第一类错误概率。 |
| 12 | A | 配对或区组设计的计量资料满足条件时，可用随机区组设计方差分析。 |
| 13 | E | 同一配伍组内非处理因素应相同或相近，以减少混杂和误差。 |
| 14 | B | 检验处理效应的 F 值分母为误差均方，对应误差自由度。 |
| 15 | D | 随机区组设计能减小误差、提高效能，但实施通常不比完全随机设计方便。 |
| 16 | E | 拉丁方设计可控制两个非研究因素，总变异分为处理、行、列、误差四部分；通常不是计算 4 个 F。 |
| 17 | D | 两阶段交叉设计通常需考虑处理、阶段、个体及误差等，不是只分解为 3 个部分。 |
| 18 | E | 交叉设计主要用于比较处理效应并控制个体差异，不是以研究个体间差异影响为目的。 |

## 05. 计数资料的统计分析

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | D | 构成比表示事物内部各组成部分占总量的比重。 |
| 2 | B | 率用于说明某现象发生的强度或频率。 |
| 3 | E | 粗死亡率分母宜用年平均人口数或年中人口数，不能用年中任意时刻人口数。 |
| 4 | B | 标准化率主要用于消除两地年龄构成不同对总率比较的影响。 |
| 5 | B | 使用相对数常见错误是把构成比误当作率来解释发生强度。 |
| 6 | E | χ²检验用于率、构成比、拟合优度和关联分析，不用于两样本均数比较。 |
| 7 | D | χ²分布形状由自由度决定，且通常为右偏分布。 |
| 8 | D | χ²统计量为平方和形式，取值范围为大于等于 0。 |
| 9 | C | 四格表周边合计固定时，理论频数由周边合计决定，不随某格实际频数改变。 |
| 10 | B | 四格表自由度为 (2-1)(2-1)=1。 |
| 11 | A | 四格表 n≥40 且 1≤T<5 时用校正 χ²检验。 |
| 12 | C | 应校正而未校正时，χ²值偏大，P 值偏小，容易夸大差异。 |
| 13 | D | 5 个样本率构成 2x5 表，自由度为 (2-1)(5-1)=4。 |
| 14 | A | 多个率比较 P<0.01，只能说明各总体率不等或不全相等。 |
| 15 | B | RxC 表中少量理论数在 1 到 5 之间且比例不高时，可直接做 Pearson χ²检验。 |
| 16 | A | 两种疗法有效率比较是四格表，df=(2-1)(2-1)=1。 |

## 06. 非参数检验

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | A | 选 t 检验还是秩和检验，要结合研究目的、设计类型、分布和数据特征。 |
| 2 | E | 方差分析属于参数检验，不属于非参数检验。 |
| 3 | E | 非参数检验适用面广但在参数检验条件满足时效能通常较低，不是效能高。 |
| 4 | E | 小样本数值变量比较要先判断是否满足 t 检验条件，再决定方法。 |
| 5 | B | 配对设计 Wilcoxon 符号秩检验的 H0 是差值总体中位数等于 0。 |
| 6 | E | 绝对值相同且符号不同时不能随意按顺序编秩，否则会影响正负秩和。 |
| 7 | D | 符号秩检验中 T 在界值范围内通常不拒绝 H0，即 P>α。 |
| 8 | D | 两样本秩和检验的无效假设通常为两总体分布位置相同，可表述为中位数相同。 |
| 9 | C | 成组两样本秩和检验通常以样本例数较小组的秩和作为统计量 T。 |
| 10 | B | 两样本秩和检验中，T 在界值范围内表示 P 大于相应概率水准。 |
| 11 | D | 完全随机设计多组等级资料比较宜用 Kruskal-Wallis H 检验。 |
| 12 | A | 秩和检验应把两组数据混合后统一从小到大编秩，不能分别编秩。 |
| 13 | B | 符合方差分析条件却用秩和检验，检验效能降低，第二类错误可能增大。 |

## 07. 双变量相关与回归

| 题号 | 答案 | 正确选项理由 |
|---|---|---|
| 1 | B | X 乘以常数会改变斜率单位，回归系数改变，截距不一定改变。 |
| 2 | C | 相关系数 r 的取值范围为 -1≤r≤+1。 |
| 3 | A | r=1 表示完全正相关，残差平方和为 0，回归平方和等于总平方和。 |
| 4 | E | 回归系数绝对值越大表示回归线越陡，不等于相关越密切。 |
| 5 | E | 相关密切程度看 |r|，绝对值越接近 1 相关越密切。 |
| 6 | A | 回归系数大小受变量单位影响，绝对值大不一定说明相关性强。 |
| 7 | C | 同一资料中直线回归系数 b 与相关系数 r 的显著性检验等价，t 值相等。 |
| 8 | B | 简单线性回归中 b=r(Sy/Sx)，当 X 与 Y 标准差相等时 b=r。 |
